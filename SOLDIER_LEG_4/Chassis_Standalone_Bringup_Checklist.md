# 无云台底盘独立模式新车烧录检查清单

本文档用于把当前无云台 C 板方案烧录到新的轮腿底盘前后的检查与校准。当前方案默认只运行底盘轮腿，由底盘板直连 DT7/SBUS 遥控器，不依赖上 C 板和云台。

调试原则：先确认硬件和总线映射，再确认零点和方向，再低功率悬空试，最后落地小速度试。任何一个环节出现方向不对、数据跳变、腿部突然动作，都应立即回到 STOP 或断电排查。

## 1. 烧录前代码配置检查

确认以下配置与独立底盘方案一致：

- `Chassis/Task/Inc/Check_Task.h` 中 `CHASSIS_STANDALONE` 为 `1`。
- `Chassis/Src/main.c` 中已经调用 `Remote_Control_Init()`。
- 底盘板 USART3 接 DT7/SBUS 遥控器。
- `Chassis/Src/stm32f4xx_it.c` 的 `USART3_IRQHandler()` 中调用 `SBUS_TO_RC()`。
- 独立模式下 `Check_Control()` 的状态逻辑为：
  - 左拨杆下：`STOP`
  - 左拨杆中：`STOP`
  - 左拨杆上：`RC`
- 独立模式下异常检查至少应检查 4 个 DM8009 关节电机在线。

注意：当前代码中 DJI3508 轮毂掉线检查被注释掉，调试方便但会掩盖轮毂反馈异常。正式跑车前建议确认轮毂反馈在线，必要时恢复轮毂掉线检查。

## 2. CAN 与电机 ID 检查

新底盘的 CAN 口、ID、物理位置必须和代码映射一致。

### DM8009 关节电机

- CAN1：
  - DM8009 ID `0x01`，反馈 `0x10`，对应 `DM_8009[0]`
  - DM8009 ID `0x02`，反馈 `0x20`，对应 `DM_8009[1]`
- CAN2：
  - DM8009 ID `0x03`，反馈 `0x30`，对应 `DM_8009[2]`
  - DM8009 ID `0x04`，反馈 `0x40`，对应 `DM_8009[3]`

### DJI3508 轮毂电机

- CAN2：
  - DJI3508 ID `0x201`，对应 `Dji_3508[1]`
  - DJI3508 ID `0x202`，对应 `Dji_3508[0]`

### 物理布局

代码注释中的底盘布局：

```text
前方

DM8009:    0       2

DJI3508:   0       1

DM8009:    1       3
```

检查要求：

- 每个 DM8009 的 ID 与物理位置一致。
- 每个 DM8009 所在 CAN 口与代码一致。
- 左右轮 3508 的 ID 与代码索引一致。
- CAN 终端电阻、接插件、线序可靠。
- 上电后 `Link_Sit.err_num` 不应出现 DM8009 掉线位。

独立模式下 DM8009 掉线位含义：

- `0x0010`：`DM_8009[0]` 掉线
- `0x0020`：`DM_8009[1]` 掉线
- `0x0040`：`DM_8009[2]` 掉线
- `0x0080`：`DM_8009[3]` 掉线

## 3. DM8009 零点与方向校准

这是新底盘最关键的校准项。腿部角度解算依赖 DM8009 的位置反馈和安装方向。

代码中的角度映射：

```c
five_link[0]->phi1 = PI - cm->DM_8009[1].pos;
five_link[1]->phi1 = PI - cm->DM_8009[2].pos;
five_link[0]->phi4 = 0  - cm->DM_8009[0].pos;
five_link[1]->phi4 = 0  - cm->DM_8009[3].pos;
```

检查要求：

- 4 个 DM8009 的机械零点已经正确写入电机。
- 标准站立姿态下，左右腿 `L0`、`phi0`、`abs_leg_theta` 数值合理且左右对称。
- 手动前后摆动左腿时，只应主要影响左腿相关数据。
- 手动前后摆动右腿时，只应主要影响右腿相关数据。
- 手动伸长腿时 `L0` 应增大，缩短腿时 `L0` 应减小。
- 左右腿向同一方向摆动时，`abs_leg_theta` 的变化趋势应与旧车一致。

建议通过 VOFA 或调试器重点观察：

- `Chassis_Motor.DM_8009[i].pos`
- `Five_Link_Parameter[0].phi1`
- `Five_Link_Parameter[0].phi4`
- `Five_Link_Parameter[0].L0`
- `Five_Link_Parameter[0].phi0`
- `Five_Link_Parameter[1].phi1`
- `Five_Link_Parameter[1].phi4`
- `Five_Link_Parameter[1].L0`
- `Five_Link_Parameter[1].phi0`
- `Leg[0].abs_leg_theta`
- `Leg[1].abs_leg_theta`

如果一进 `RC` 腿猛伸、猛收、左右交叉或输出长时间打满，优先排查 DM8009 的 ID、CAN 口、零点和方向。

## 4. IMU 姿态方向检查

底盘控制直接使用 BMI088/INS 的姿态结果。当前底盘侧使用方式：

```c
body->yaw     =  ins->Yaw * Ang_PI;
body->d_yaw   =  ins->Gyro[2];
body->theta   = -ins->Roll * Ang_PI;
body->d_theta = -ins->Gyro[1];
```

独立模式下：

```c
body->abs_yaw = body->yaw;
```

检查要求：

- 车体水平静止时，`Roll`、`Pitch` 接近 0。
- 车体向前、向后轻轻俯仰时，`body->theta` 方向与旧底盘一致。
- 抬起车体一侧产生 roll 时，左右腿补偿方向正确，不应越补越歪。
- 静止时 `Gyro[1]`、`Gyro[2]` 零漂不要过大。
- 新底盘 IMU 安装方向必须和代码假设一致。

如果 IMU 安装方向和旧底盘不同，不要直接跑车，应先修改坐标符号或安装方向。

## 5. 轮毂方向与反馈检查

轮速解算中左右轮符号不同：

```c
leg[0]->wheel_s = -(cm->Dji_3508[0].speed_rpm / Gear_Ratio / 60.0f) * 2.0f * PI * R_wheel;
leg[1]->wheel_s =  (cm->Dji_3508[1].speed_rpm / Gear_Ratio / 60.0f) * 2.0f * PI * R_wheel;
```

悬空检查要求：

- 手动向前转左轮时，`Leg[0].wheel_s` 变化方向应与旧车一致。
- 手动向前转右轮时，`Leg[1].wheel_s` 变化方向应与旧车一致。
- 遥控器给极小前进量时，两边轮子应同时向前转。
- 遥控器给极小 yaw 量时，两边轮子应反向转。
- 左右轮反馈不能互换。

如果轮速方向不对，优先检查 ID、线序、减速箱安装和电机方向，再考虑改代码符号。

## 6. 遥控器通道检查

当前独立模式直接使用 DT7/SBUS 遥控器。

检查要求：

- 左拨杆下时，`Controlled_State` 为 `STOP`。
- 左拨杆中时，`Controlled_State` 为 `STOP`。
- 左拨杆上时，`Controlled_State` 才进入 `RC`。
- 遥控器断电或接收异常时，系统应进入安全状态，不应保持上一次速度。
- 前后、左右、旋转通道方向与旧底盘一致。
- 遥控器中位时，目标速度和目标 yaw 输入接近 0。

建议新底盘调试期间保留“左拨杆中位也是 STOP”的逻辑，待底盘稳定后再开放其他模式。

## 7. 第一次上电安全流程

第一次烧录到新底盘时，按以下顺序执行：

1. 架空整车或拆轮，确保轮子和腿部动作不会伤人或撞机械限位。
2. 遥控器左拨杆保持下档 `STOP`。
3. 使用限流电源或低风险供电方式，先不要直接满功率测试。
4. 上电后等待初始化蜂鸣完成。
5. 检查 `Link_Sit.err_num`，确认 4 个 DM8009 均在线。
6. 保持 `STOP`，确认 4 个 DM8009 没有突然抽动。
7. 检查 CAN 反馈、遥控器数据、IMU 数据、腿部解算数据。
8. 左拨杆上档进入 `RC`，只给极小输入。
9. 如果有异常动作，立即回 `STOP` 或断电。

## 8. 悬空腿控静态检查

落地前必须先悬空或半支撑检查腿控。

重点观察：

- `L0` 目标腿长和实际腿长接近。
- 左右腿高度基本一致。
- `joint_m[0]->T_A`、`joint_m[0]->T_E`、`joint_m[1]->T_A`、`joint_m[1]->T_E` 不应长期打满。
- 轻轻扰动腿部时，控制输出应抵抗扰动，不应顺着扰动发散。
- `fall_flag`、`theta_flag`、`off_flag` 不应静止误触发。
- `Roll_Pid.Output` 和重力补偿输出不应明显异常。

异常现象与优先排查方向：

- 腿突然伸满或缩满：查 DM8009 零点、方向、腿长解算。
- 左右腿动作互换：查 DM8009 ID、CAN 口、代码索引。
- 一进 RC 就输出打满：查 IMU 方向、腿杆角度、PID 输入方向。
- 轮子原地狂转：查遥控器通道、3508 ID、轮速符号。

## 9. 落地低速测试

悬空测试通过后再落地。

测试顺序：

1. 空旷地面，低腿长、低速度。
2. 先只试前后小速度。
3. 再试小 yaw。
4. 再试急停。
5. 再试遥控器断链。
6. 最后逐步提高速度和转向幅度。

观察重点：

- 车体是否原地自转。
- 前进命令是否变成后退。
- 左右腿是否高度不一致。
- roll 补偿是否越补越歪。
- 小扰动后是否振荡发散。
- 急停是否能及时进入安全状态。

## 10. 建议的临时保护

新底盘第一次调试建议增加或保留以下保护：

- 恢复或临时打开 DJI3508 轮毂掉线检查，避免轮毂反馈异常被掩盖。
- 初期降低 DM8009 力矩上限，例如先把关节输出限制在较小范围，确认方向后再恢复。
- 初期降低遥控器速度和 yaw 输入比例。
- 保留左拨杆中位 `STOP`，只用上档进入 `RC`。
- 调试时让一人拿遥控器，一人看电源和机械状态，确保可以立即断电。

## 11. 推荐调试顺序

推荐按以下顺序完成，不要跳步：

1. 代码配置确认。
2. CAN 口、ID、物理位置确认。
3. DM8009 零点与方向确认。
4. IMU 姿态方向确认。
5. DJI3508 轮毂反馈与方向确认。
6. 遥控器通道确认。
7. STOP 模式上电检查。
8. 悬空 RC 小输入检查。
9. 半支撑腿控检查。
10. 落地低速前后测试。
11. 落地低速 yaw 测试。
12. 急停和遥控器断链测试。
13. 逐步恢复正常输出限制和速度限制。

完成以上检查前，不建议让新底盘直接站立高速跑。
