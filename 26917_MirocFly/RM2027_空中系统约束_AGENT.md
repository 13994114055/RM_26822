## A. 尺寸 / 重量 / 能源(空中机器人)

- A1 [S][规范 §2.4.4 表2-9] 重量-尺寸联动:检录实测重量 x∈[0.15, 0.249]kg;任意情况下长宽高 ≤ y×y×y,**y = round((0.3225 − x) / 0.001225) mm**;x < 0.15kg → y = 141mm(**无最小重量下限**;141mm 为长/宽/高各自上限)。越重必须越小(150g→141 / 200g→100 / 249g→60)。
- A2 [S] 最大供电总容量 ≤ 4Wh(**单机口径**:该机全部电池合计;四台各自独立,不存在四台合计;机库 300Wh 另计)。计量口径(标称/满电、是否加总)见 H7。
- A3 [S] 内部任意时刻任意一点电压相对电池负极 ≤ 30V。
- A4 [S] 禁止安装发射机构。
- A5 [S][S75] 持续悬停 ≥ 10 秒。
- A6 [G][表2-1] 电池类型:DJI 电池、正规厂家干电池、正规厂家锂电池(空机三级全允许)。
- A7 [G][§2.4] 坐标系:X/Y 方向任选,Z 垂直于放置平面。最大伸展尺寸含裁判系统及其支架(不适用空机,空机无裁判系统)。
- A8 [S][S77] 自备与尺寸匹配的刚性敞口容器(如无盖箱体);容器内径不得超出重量对应限值;任意伸展状态不得超出容器内部空间;检录时按实测重量计算限值并放入容器验证。

## B. 结构 / 飞行安全(空中机器人)

- B1 [S][S78] 桨保:完全覆盖各桨叶旋转扫掠空间(上方、下方、周向连续封闭边界);**孔径 < 17mm**;运行中不得因断裂/脱落/变形侵入扫掠空间。
- B2 [S][S78] 桨保检录测试:①17mm 弹丸置于防护结构任意位置不可穿过;②500mm 高度从底面、侧面、顶面自由下坠至覆盖地胶平面,防护结构及桨叶无明显变形或损坏。
- B3 [G][S78] 桨叶建议柔性材料。
- B4 [S][S80] 航行外观灯:圆形灯组,顶面中心;稳固连接、自然贴合,无歪斜/偏移/局部遮挡/悬空/鼓包/褶皱;安装面法向与 Z 轴夹角 ≤10°;安装面位于机体最高面(电机、电机架、桨叶除外)。
- B5 [S][S80] 灯组规格:XL-3528SURUBC 灯珠(红蓝双色,SMD3528,无内置控制 IC,正面发光),**数量 7**,均匀分布且中心须有 1 颗,最外缘包络圆直径 ≤24mm;直流驱动,**禁 PWM/扫描**;指定相机曝光内无明暗条纹/帧间亮度波动;无亮度/颜色差异;红 #FF0000 / 蓝 #0000FF(单色导通)。
- B6 [G][S81] 可加通信指示灯,颜色与队伍一致。
- B7 [S][S79] 急停:遥控器仅与该遥控器配对;**任意时刻可同时控制场上所有己方空中机器人紧急停桨**;**任意时刻失去遥控器信号 → 自动停桨**(检录时关闭遥控器演示)。
- B8 [S][§2.1.5/S31-S34/S57] 通用:禁尖锐结构;线路整齐无金属线芯裸露;禁易碎/易脱落材料(羽毛棉絮);禁胶类连接场地/道具。S33:渔网可作空机保护罩。
- B9 [S][S66] 机器人尺寸变化不得拆分为独立单体;禁柔性牵引连接(线缆/绳索/链条/皮带)、依赖吸附/摩擦维持连接。
- B10 [R][R48] 运行约束:不得飞出战场外(战场 28m×15m,围挡上沿 2.4m;高度判定基准待答疑)。

## C. 电气 / 无线 / 遥控

- C1 [S][S19] 发射端(遥控器)白名单:DT7 / 富斯 i6X / 天地飞 ET08、ET08A / 天地飞 ET16S、ET16;**不得使用同款其他型号**;仅允许 2.4G;禁改装无线射频部分(S21)。
- C1a [G] **协议判定**:规则全文不含接收机/协议条款——接收机→FC 串行协议不违规,硬约束只在发射端型号。白名单机型典型链路:DT7+DR16→DBUS(反相 TTL,需反相器/官方口);i6X+FS-iA6B→PWM/PPM/i-BUS/S.BUS;ET16S+RF209S→PWM/PPM/W.BUS(兼容 S.BUS)。CRSF 只存在于 ELRS/TBS 生态 → 发射端必然非白名单 → 现有 "serial+CRSF" 链路不合规(除非走 C1b)。
- C1b [G] **灰区(待答疑 H9)**:ET16S 官方参数页支持"外置协议:ExpressLRS/CRSF/SBUS/MULTI/PPM/W.CRSF"——"白名单机型+外置 CRSF/ELRS 高频头"是否合规不明;答复前按不合规处理。
- C2 [S][S20] 空机例外:遥控器不要求与接收机一一对应(为"一控多机急停"服务);其他机种必须一一对应。
- C3 [S][S22] 除可见光通信外,不得搭载除遥控器、裁判系统、雷达信息接收装置以外的无线通讯设备;可见光通信仅限参赛机器人之间。
- C4 [S][S23] 不得产生 0.428-0.438GHz、2.3-2.55GHz、3.75-4.75GHz、5-7.5GHz 无线信号干扰。
- C5 [S][S60] 运算平台使用操作系统必须开源(Linux/RTOS 等;禁 Windows/macOS)。
- C6 [G][§2.1.2] 控制方式:遥控器(杆量)、相机图传接收端(键鼠/杆量)、图传链路(自定义终端)、裁判系统串口(多机通信);组委会推荐图传链路/图传接收端控制。
- C7 [G][表2-9] 空机在机库内可与机库通信;多机通信仅允许通过机库间接通信(表3-7)。

### 项目绊线(高风险,评审必查)

- T1 [C3/C4] LicheeRV Nano 板载 WiFi/BT 位于 2.3-2.55GHz → 比赛上场前必须禁用/移除,并保留可验证证据;禁止以任何形式恢复。
- T2 [C1] 急停/遥控链路:现有 "serial+CRSF" 接收机(配套发射端为 ELRS/TBS 系)不在白名单 → **整条链路不合规**;替换方案=白名单发射端+其原生接收机(DBUS/SBUS/iBUS),FC 仅改 UART 协议配置。想保留 CRSF 接收机只能走 C1b 灰区(先答疑)。
- T3 [B7] 急停必须"一个发射端停全部己方场上空机"+失联自停;若沿用 ch5 锁桨方案,需验证:多机同模型绑定、信号丢失行为、检录演示流程。
- T4 [A3] 满电电压:锂电池 4.2V/cell 计算电池组串数对应总电压 ≤30V(A2 的 4Wh 才是更紧的约束)。

## D. 裁判系统(全部装在机库)

- D1 [G][表3-3/表2-10] 空中系统裁判系统 = 主控 ×1 + 电源管理 ×1 + 相机图传发送端 ×1;空机本体不带任何裁判系统模块。
- D2 [S][S109] 机库主控红外接收器朝向能量机关立柱 150×150mm 红外发射区(沿柱宽居中,下边缘与机库平台底面齐平);准备阶段上电未连上可在红外范围内调整。
- D3 [G][§3.3] 主控:上表面水平朝上;天线中心存在 60° 锥角无导电遮挡;散热良好;屏幕/按键/接口/红外接收器不遮挡;Logo 下 8.5mm 为中心 70mm 半径上半球无导电/电磁吸收/干扰物。
- D4 [G][§3.9] 图传发送端:相机正前方 60° 锥角无导电材料;进/出风口 150mm 内无遮挡;天线半球 70mm;接口/指示灯无遮挡。
- D5 [S][S105/S106] 禁拆卸/改装裁判系统机载端;仅可安装当赛季借用的裁判系统。
- D6 [G][规范表3-1] 更换时限:主控 5min / 电源管理 10min / 图传 5min(检录与比赛期间)。检录涉及多次拆装,结构设计要快拆。
- D7 [G][规范表3-4] 电源管理接口(机库):Chassis 不供电;Gimbal=执行机构电源;Ammo 不供电;Mini PC=Mini PC 电源;输入 22-26V。
- D8 [G][规则 表5-4] 机库异常离线 → 执行机构断电 + 多机通信断开。

## E. 再设计 / 知识产权 / 提交

- E1 [S][S61/S62] 检录前提交去保护壳主体照片(指定渠道);使用整机成品/开源方案需提交改动点说明文档。
- E2 [S][S64] 空中机器人与机库为**独立再设计判定单元**,各需 ≥1 项充分再设计 或 ≥3 项非充分再设计(条件不跨单元合并)。
- E3 [G][§2.2.1] 充分再设计(空机):升力单元总体布置或姿态控制机构原理改变;机体主要承载体系改变。充分(机库):出入库/转运/对接核心机构原理或运动链拓扑改变。
- E4 [G][§2.2.2] 非充分再设计:局部气动几何参数变化>10%;机库动力电机减速比/局部传动路径变更;增加感知/反馈/执行模块;动力源变更;材料更换并调整质量分布等。
- E5 [G][§2.2.3] 无效再设计:只换桨叶/电机/电池/飞控型号;只改 PID/固件配置;只加非主要承载桨保;机库仅换外箱/舱盖/复制相同停机位。
- E6 [G][S65] 禁第三方成品模组/成品系统(机械臂、底盘、云台、飞镖、成品飞控整机等);市售通用产品豁免条件(公开销售、通用用途、单价 ≤5000 元(模组)/8000 元(系统)、运算平台算力豁免 ≤160 TOPS INT8 稀疏 或 Σ(主频×核数)≤25GHz 等)。
- E7 [R][R37] 争议时队伍有责任展示机械/电路图纸与代码文件。

## F. 运行时行为约束(比赛阶段)

- F1 [R][表3-7] 空机初始区域=机库;仅能把空中系统安装在己方机库平台(4.3.2.2)。
- F2 [R][R47] 三分钟准备阶段:可在机库平台及其初始区域附近调试,但**不得启动桨叶**。
- F3 [R][R48] 不得飞出战场外;违规:红牌 + 同场次其他局该空中系统不得上场。
- F4 [R][R49] 故障,或因**动力系统与供电系统设计不合理**导致战损 → 需裁判检查 + 主裁判确认无安全隐患才可继续;违规:红牌 + 同场次其他局不得上场;飞行不稳定会被主裁判罚下。
- F5 [R][R30] 安全员仅紧急时操作急停遥控器;违规操作 → 空中系统红牌。
- F6 [R][R55] 不得主动携带对方飞镖和对方空中机器人。
- F7 [R][R62] 不得使用 42mm 弹丸、飞镖、空中机器人击打能量机关和机库。
- F8 [R][R64] 机器人和空中系统不得违规进入飞镖发射站禁区。
- F9 [R][7.1.2] 空中系统被罚下 → 机库断电,飞行中立即停桨;指挥手被罚下 → 空中+飞镖系统均被罚下。
- F10 [R][R29] 指挥手:可同时配置机库遥控器、飞镖遥控器、自定义终端;准备阶段结束后不得移动位置。
- F11 [G][表5-2/表5-25] 冲击基础伤害:对机器人装甲/基地装甲/前哨站中部装甲各 200;受攻击增益放大、防御增益减免;自适应装甲(仅弹丸)与雷达易伤(仅地面机器人)不适用。
- F12 [G][表5-1] 冲击检测参数(接触时间、面累积冲量)官方待定 → 在确定性发布前,撞机策略/结构测试以"能稳定产生可检测冲击"为目标预留余量。
- F13 [G][S22] 自建光通信/定位链路:按 S22 排除法结构解释,"可见光通信"被单独豁免 → 光通信(含不可见红外)倾向纳入"无线通讯设备",且豁免仅限机器人之间;场地布设发射源另撞 R3/R59/"未授权即禁止"逻辑 → **未经书面答疑前禁止采用**(项目已决定 FPGA/外部光定位存疑暂停,见 H10)。

## I. Agent 设计评审自检问句(每次评审逐条过)

1. 当前 BOM 总重下,允许的 y 是多少?最坏姿态是否会超?(A1/B10)
2. 桨保孔径实测值?跌落测试是否做过且留下证据?(B1/B2)
3. 全部无线设备清单?哪些在比赛时必须关闭/移除?急停发射端是否在白名单?(C1/C3/T1/T2)
4. 急停链路能否"一键停全部"?失联时固件的默认行为是什么?(B7/T3)
5. 固件/上位机是否有出界保护(地理围栏)与失控降落策略?(B10/F3)
6. 电池标称容量与满电电压是否满足 4Wh/30V?(A2/A3)
7. 机库主控红外朝向方案是否已按 150×150mm 区域设计?(D2)
8. 撞击损伤后结构可维护性(快拆/换件时限)是否满足检录节奏?(D6)
9. 是否触碰再设计红线(如直接使用开源整机方案未做再设计)?(E2-E5)
10. 检录演示脚本(悬停/急停/灯组)是否准备并演练过?(§G)
11. 遥控/急停链路的发射端型号是否在白名单?接收端协议无关,但射频生态必须匹配?(C1/C1a/T2)
12. 是否存在任何自建光/无线外部定位或通信(信标、基站、外挂链路)?未经答疑答复一律不得进入设计?(F13/H8/H10)

## J. 变更时机(现改 vs 临赛再调)
